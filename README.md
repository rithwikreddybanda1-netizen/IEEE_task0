# IEEE Task 0

This repository contains six introductory Python exercises covering lists, functions, prime numbers, NumPy, pandas, and Matplotlib.

## Requirements

- Python 3.10 or newer

The third-party Python packages used by the exercises are:

- NumPy
- pandas
- Matplotlib

## Run the exercises

Questions 1–3 prompt for input in the terminal. 
Question 4 prints NumPy calculations. 
Question 5 reads 'student_performance.csv', processes it, and writes 'final_student_performance.csv'. 
Question 6 reads 'final_student_performance.csv' and opens four graphs.

Run Question 5 before Question 6 when starting from a fresh clone so that the processed CSV is generated. 
Close each graph window to allow Question 6 to continue to the next graph.

## Exercise summary

Script           : What it does 

- IEEE_task0_Q1.py : Reads a list of integers and reports its minimum, maximum, even/odd sums, and reverse.
- IEEE_task0_Q2.py : Copies a list, removes negative values, appends `0`, and sorts it.
- IEEE_task0_Q3.py : Prints prime numbers below a user-provided upper limit.
- IEEE_task0_Q4.py : Demonstrates basic NumPy array statistics and Boolean indexing.
- IEEE_task0_Q5.py : Uses pandas to inspect and transform student-performance data.
- IEEE_task0_Q6.py : Visualizes the processed student-performance data with Matplotlib.
